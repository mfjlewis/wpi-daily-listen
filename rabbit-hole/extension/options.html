Rabbit Hole

Connect the extension to your Rabbit Hole app.

How to use it

  • Toolbar button or Alt+Shift+S: save the page you're reading. If you've selected text, it's saved as a highlight too.
  • Right-click selected text → "Save selection to Rabbit Hole as a highlight".
  • Right-click a link → "Save link to Rabbit Hole", without opening it.
  • In the popup, Screenshot visible part adds what's on screen as a highlight.

The extension sends the page as you see it, so articles you're logged in to can be saved.
