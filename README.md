# WPI Daily Listen

Plain HTML monologue pages for Mike Lewis / Where Peter Is morning roundups.
Open a dated `WPI-Brief-YYYY-MM-DD.html` page in Chrome for Android and use **Listen to this page**.

## Rabbit Hole (prototype)

`rabbit-hole/` is a separate prototype: a research archive that saves links, translates and tags them, keeps citations, and reads them aloud. See [rabbit-hole/README.md](rabbit-hole/README.md).
